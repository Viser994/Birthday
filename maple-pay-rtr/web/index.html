Integrate in three steps

      
    
        
  1. 
          Add one header.
          X-API-Key: maple_sandbox_dev_key
          You can also use Authorization: Bearer maple_sandbox_dev_key.
        
    2. 
        
  2. 
          POST /v1/payments with amount, payer, and payee.
          Skip ISO fields. We create UETR, message IDs, settlement date, and agent IDs.
        
    3. 
        
  3. 
          Read status, not HTTP 201.
          pending means still moving, accepted means settlement started,
          completed means funds settled, rejected means nothing moved.
          Poll GET /v1/payments/{id} or send ?wait_for_result=true.
